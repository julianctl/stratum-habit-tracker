# Stratum — Obsidian Habit Tracker

A habit tracking dashboard built into Obsidian. View your habits as a calendar heatmap or a date matrix, log daily completions, manage a daily to-do list, and write daily notes — all without leaving your vault. No external server or database: all data lives in your vault and syncs via Obsidian Sync.

## Features

- **Habit Matrix** — habits as rows, dates as columns. Click a cell to toggle completion for that day; right-click to attach a note. Week view, plus a scrollable, configurable rolling window (default 50 days) for the month view.
- **Year Overview heatmap** — completion density over the past year, with intensity scaled to how many of your habits you completed each day. The base color is configurable.
- **Per-habit configuration** — rename, set a custom color, and assign a category. Habit colors default to their category's color (live-derived) and can be overridden per habit.
- **Daily to-dos** — add, check off, and delete to-do items in the sidebar.
- **Daily notes** — open or create today's note as a real Markdown file in a configurable vault folder, so it's searchable, linkable, and appears in graph view.

## Data storage

- **Plugin data** (`data.json`) holds habit definitions, categories, habit logs (one entry per habit per completed day — existence means done), and to-dos.
- **Daily notes** are plain Markdown files in a user-configurable folder (default: `Stratum/Daily Notes/`), named `YYYY-MM-DD.md`.

## Settings

- **Daily notes folder** — where daily notes are created and read.
- **Heatmap color** — base color for the Year Overview heatmap.
- **Matrix range (days)** — default number of days shown in the matrix month view.

## Development

```bash
npm install
npm run dev    # watch + rebuild on save
npm run build  # type-check + production build
npm run lint   # eslint
```

The build output (`main.js`) is generated by esbuild and is not committed; it is bundled for releases.

## Requirements

Requires Obsidian **1.7.2** or newer.
